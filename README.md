# Проект каталога товаров на Django

Учебный проект для демонстрации работы фреймворка Django, шаблонизатора и интеграции Bootstrap.

## Стек технологий
- Python 3.x
- Django 5.x
- SQLite
- Bootstrap 5

## Запуск проекта
1. С клонировать репозиторий
2. Создать виртуальное окружение: `python -m venv .venv`
3. Активировать окружение: `source .venv/bin/activate`
4. Установить зависимости: `pip install -r requirements.txt`
5. Применить миграции: `python manage.py migrate`
6. Запустить сервер: `python manage.py runserver`
